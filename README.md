# Amir Creepy - Discord Developer

## Installation

To use this project, simply open the `index.html` file in your web browser. No additional installation is required.

## Usage

The website features a particle background and a simple interface with a profile image, name, and social media links. Users can click on the social media icons to visit the corresponding profiles.

The website also includes a "Buy Me a Coffee" button that links to a coffee donation page.

## Contributing

This project is a personal website and is not open for contributions. However, if you have any feedback or suggestions, feel free to reach out to the project owner.
